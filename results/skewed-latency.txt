submit-to-completion latency
============================
Latency is measured per task from the submit call to the moment the task
returns; for the pool and the scheduler that includes queueing time, while for
the naive implementation it is almost pure service time.

The first block reports the median run of each cell. The second reports how
far the p99 moved across the repetitions, because a tail figure from a single
run should not be trusted on its own.
